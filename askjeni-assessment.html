What will the following React component render on the first click of the button?
Consider the behaviour of useState when the setter is called with the same value as the current state.
import React, { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  const handleClick = () => {
    setCount(count + 1);
    setCount(count + 1);
  };

  return <button onClick={handleClick}>{count}</button>;
}
The button displays 2 — both setCount calls execute synchronously
The button displays 1 — React batches state updates within the same event handler
The button displays 0 — state updates are asynchronous and don't apply until the next render
The component throws a runtime error due to multiple setCount calls in one handler
